GYMCOACH — VERSIÓN WEB INSTALABLE (PWA)

No es una APK. Necesita publicarse en HTTPS para poder instalarse como app.

SIN ORDENADOR (ANDROID):
1. Descomprime gymcoach-web.zip desde Archivos en tu teléfono.
2. Abre https://app.netlify.com/drop en Chrome, inicia sesión y sube la carpeta gymcoach-web (si el selector móvil no permite carpetas, usa otro servicio de hosting estático que acepte ZIP, como Cloudflare Pages mediante GitHub).
3. Abre la URL HTTPS publicada.
4. En Chrome, menú ⋮ > Añadir a pantalla de inicio > Instalar (si aparece).

La disponibilidad de subida de carpetas desde móvil depende del navegador y el proveedor. Como alternativa, puedes subir estos archivos a un repositorio GitHub desde el móvil y activar GitHub Pages en Settings > Pages > Deploy from branch.

IMPORTANTE: Los datos se guardan solo en el navegador del dispositivo (localStorage). Exporta copias JSON en Inicio. No borres los datos del navegador si quieres conservar tus entrenamientos. No hay sincronización ni cuentas todavía.
